# Fintech Wallet App (React Native)

Complete cross-platform digital wallet with biometric login, QR payments, transaction history, and offline mode.

## Features
- Biometric authentication
- QR code payments
- Offline support + sync
- Encrypted API communication
- Real-time WebSocket updates
- Secure local storage (Keychain / Keystore)

## Tech Stack
React Native • TypeScript • React Native-cli • React Navigation • AsyncStorage + SecureStore
